📊 SpendSense AI — Architecture & Function-Calling Flow

Procurement Spend Analytics Assistant · ask your data in plain English

What it does: You ask things like “Who were my top 5 suppliers by spend in FY2024?” or “How much maverick spend did we have in IT Hardware?”. The assistant uses OpenAI function calling to turn your question into a precise call on an analytics function, runs it over the spend dataset with pandas, and answers in plain English — often with a small table.

Key concept (recap): what “function calling” really is

The AI does NOT run code. It only chooses a function and fills in the arguments as JSON. Your Python runs the function and sends the result back. Then the AI writes the human answer. Think of GPT as a smart receptionist who fills out the right request form; your code is the back office that actually does the work.

The round-trip flow

Notice GPT is called twice per question — once to pick the function, once to explain the result.

You

1 · Ask a question in plain English

"Top 5 suppliers by spend in FY2024, IT Hardware only"
sent with the list of available tools
GPT · call #1

2 · GPT decides which function to call

It reads your question + the tool definitions and returns a structured tool_call (no prose yet).

tool_call: top_suppliers( n=5, category="IT Hardware", start_date="2023-10-01", end_date="2024-09-30" )
your code reads the tool_call
Python

3 · Your code runs the real function

A plain Python/pandas function filters & aggregates the dataset. This is where the actual analytics happens — the numbers are never invented by the AI.

Data

4 · pandas reads the spend CSV

data/procurement_spend.csv — 2,600 purchase orders, 8 categories, 37 suppliers, 2 fiscal years.

result (JSON) goes back up to GPT
Result

5 · Function result handed back to GPT

[{"supplier":"Dell Technologies","spend":4821000}, {"supplier":"HP Inc.","spend":3990500}, ...]
GPT · call #2

6 · GPT turns numbers into a human answer

Second call: GPT receives the result and writes the explanation (and can format a table).

"In FY2024, your top IT-Hardware suppliers were Dell ($4.82M), HP ($3.99M), Lenovo ($3.1M)…"
You

7 · You read the answer & ask a follow-up

The loop repeats; earlier turns stay in the conversation for context.

How this differs from ShopAssist (and why it scores well)

ShopAssist

Rigid staged flow. The code decided the steps; GPT just chatted and we manually parsed a dictionary out of its text.

SpendSense (function calling)

GPT dynamically chooses which function to run and extracts typed arguments itself — no fragile text parsing. This is exactly the capability the assignment rewards.
